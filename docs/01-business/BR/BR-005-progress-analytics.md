# BR-005: Отслеживание прогресса и аналитика

## Статус

| Параметр | Значение |
|----------|----------|
| **Статус** | ✅ APPROVE |
| **Дата утверждения** | 2026-04-29 |
| **Комментарий** | Для MVP "Trainer Diary" аналитика не входит в scope; расширенная история и аналитика — после MVP |
| **Приоритет MVP** | Phase 2 для истории и аналитики |

## Business Value

Помогает тренеру видеть факт выполнения плана клиентом, что повышает ценность trainer-first рабочего контура (Phase 2).

## Приоритет реализации

- **MVP "Trainer Diary":** статус выполнения, клиентский просмотр прогресса, полноценная история и аналитика не входят в MVP.
- **Phase 2 / P1+:** отчёты по периодам, adherence, замеры, cohort-аналитика, прогнозы, premium-отчёты, cross-client benchmark и другие расширенные аналитические представления.


## User Stories

### US-R005-001: Просмотр динамики клиента тренером

**Приоритет:** Phase 2.

* **As a** тренер
* **I want** видеть статусы выполнения по плану
* **So that** удерживать клиента через доказуемый прогресс

**Acceptance Criteria:**

* **AC-R005-U001-001:**
    * **Given:** клиент оставил отметку выполнения
    * **When:** я открываю его карточку
    * **Then:** вижу статус выполнения назначенного плана
* **AC-R005-U001-002:**
    * **Given:** за период накоплены данные
    * **When:** я открываю карточку клиента
    * **Then:** система показывает выполненные и невыполненные элементы плана

### US-R005-002: Просмотр собственного прогресса клиентом

**Приоритет:** Phase 2 / за пределами MVP "Trainer Diary".

* **As a** клиент
* **I want** видеть свою историю тренировок и статусы выполнения программы
* **So that** отслеживать собственный прогресс и оставаться мотивированным

**Acceptance Criteria:**

* **AC-R005-U002-001:**
    * **Given:** я отмечал выполнение тренировок
    * **When:** открываю раздел прогресса в своём профиле
    * **Then:** вижу список выполненных и пропущенных тренировок за период

## System Constraints

| Constraint   | Value     | Notes |
|--------------|-----------|-------|
| Latency      | < 1000 ms | Открытие истории клиента |
| Throughput   | 20 req/sec | Просмотр карточек клиентов |
| Availability | 99.5%     | Важна корректность данных |

## Метрики успеха

- ≥ 60% активированных тренеров открывают карточку клиента хотя бы 1 раз в неделю;
- ≥ 50% активированных тренеров просматривают статусы выполнения в первые 14 дней после активации.
- ≥ 50% созданных планов переиспользуются или ищутся в течение 14 дней;
- качественная обратная связь тренера анализируется для планирования Phase 2.

## Границы интерпретации

- Отсутствие отметки выполнения может означать, что клиент сообщил результат тренеру вне продукта.
- Базовый статус выполнения не входит в MVP "Trainer Diary".
- Запросы на клиентский кабинет, историю, `AccessGrant`, графики и экспорт фиксируются как Phase 2-сигналы.


## Out of Scope

- Предиктивная аналитика здоровья
- Диагностические рекомендации
- Отдельный отчётный модуль, графики замеров, adherence-отчёты, premium analytics и экспорт отчётов до Phase 2
- Клиентский кабинет прогресса и переносимая история клиента в MVP "Trainer Diary"
