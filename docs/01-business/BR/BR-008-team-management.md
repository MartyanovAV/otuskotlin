# BR-008: Управление командой студии

## Статус

| Параметр | Значение |
|----------|----------|
| **Статус** | ✅ APPROVE |
| **Дата утверждения** | 2026-04-29 |
| **Комментарий** | Основа expansion в сегмент small teams |
| **Приоритет MVP** | Phase 2 |

## Business Value

Позволяет малой студии стандартизировать сервис, распределять роли и удерживать клиентскую базу внутри команды.

## Приоритет реализации

- **Связь с MVP:** не входит в обязательный первый коммерческий релиз; MVP сохраняет только design reserve для будущей командной модели.
- **Design-partner пилоты:** допустимы после Gate 1 как контролируемая проверка спроса малых команд, без включения командного сценария в объём MVP.
- **Цель Phase 2:** роли команды, распределение прав, командный тариф, совместные операции с клиентами и базовая админка малых команд.


## User Stories

### US-R008-001: Подключение специалистов с ролями

* **As a** владелец студии
* **I want** добавлять специалистов с ролями
* **So that** стандартизировать работу команды с клиентами

**Acceptance Criteria:**

* **AC-R008-U001-001:**
    * **Given:** у меня командный тариф
    * **When:** я добавляю сотрудников
    * **Then:** могу назначать им роли и уровень доступа
* **AC-R008-U001-002:**
    * **Given:** клиент работает с несколькими сотрудниками студии
    * **When:** они входят в систему
    * **Then:** каждый видит только свой операционный контур

## Целевые допущения Phase 2

| Constraint   | Value     | Notes |
|--------------|-----------|-------|
| Latency      | < 1000 ms | Целевая гипотеза Phase 2 для назначения ролей и проверки прав |
| Throughput   | 20 req/sec | Стартовая гипотеза для design-partner пилотов small teams |
| Availability | 99.5%     | Целевая доступность Phase 2; консистентность прав критична для доверия |

## Метрики успеха

- 40+ team accounts к концу 24-го месяца;
- ≥ 70% design-partner студий подтверждают готовность платить за командный сценарий.


## Out of Scope

- HRM-функции и кадровый документооборот
- Полноценный club ERP и расписание залов
