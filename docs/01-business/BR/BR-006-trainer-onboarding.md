# BR-006: Онбординг тренера и подключение клиента

## Статус

| Параметр | Значение |
|----------|----------|
| **Статус** | ✅ APPROVE |
| **Дата утверждения** | 2026-04-29 |
| **Комментарий** | Критично для time-to-value MVP с публичной ссылкой |
| **Приоритет MVP** | P0 (Must Have) |

## Business Value

Сокращает путь к первой ценности и снижает потери в активации тренера.

## Приоритет реализации

- **MVP с публичной ссылкой:** регистрация тренера, создание первой клиентской карточки, создание первого плана, получение публичной ссылки и просмотр статуса выполнения.
- **Phase 2:** полноценная рабочая панель, импорт из сторонних систем, сегментированные onboarding playbooks, автоматические lifecycle-коммуникации.


## User Stories

### US-R006-001: Быстрое создание первого сценария с публичной ссылкой

* **As a** тренер
* **I want** быстро создать клиентскую карточку, план и ссылку
* **So that** начать работу без длинного онбординга

**Acceptance Criteria:**

* **AC-R006-U001-001:**
    * **Given:** я зарегистрирован как тренер
    * **When:** создаю клиентскую карточку и первый план
    * **Then:** получаю публичную ссылку, которую могу отправить клиенту
* **AC-R006-U001-002:**
    * **Given:** клиент открыл ссылку и отметил выполнение
    * **When:** я открываю его карточку
    * **Then:** вижу статус выполнения без клиентской регистрации и без AccessGrant

### US-R006-002: Минимальный список клиентов

* **As a** независимый тренер
* **I want** видеть клиентские карточки и их статусы
* **So that** быстро перейти к карточке клиента и назначенному плану

**Acceptance Criteria:**

* **AC-R006-U002-001:**
    * **Given:** у меня несколько клиентов
    * **When:** я работаю в FitBridge
    * **Then:** вижу список клиентских карточек, статус плана и статус выполнения
* **AC-R006-U002-002:**
    * **Given:** клиентская карточка создана
    * **When:** открываю его из списка
    * **Then:** вижу карточку клиента, назначенный план, публичную ссылку и статус выполнения

## System Constraints

| Constraint   | Value     | Notes |
|--------------|-----------|-------|
| Latency      | < 900 ms  | Для первичных действий онбординга |
| Throughput   | 30 req/sec | При массовых приглашениях |
| Availability | 99.5%     | Влияет на активацию и конверсию |

## Метрики успеха

- activation rate тренеров: ≥ 55% достигают «клиентская карточка + план + публичная ссылка» в течение 7 дней;
- ≥ 50% отправленных активных ссылок получают хотя бы одну отметку выполнения в течение 14 дней;
- median time-to-first-plan-link ≤ 1 день.


## Out of Scope

- Полноценный маркетплейс лидогенерации для тренеров
- Автоматическая миграция из всех сторонних систем без ручной поддержки
- Расширенная рабочая панель с приоритизацией клиентов и lifecycle-коммуникациями
- Регистрация клиента, клиентский кабинет и полноценный AccessGrant в MVP публичного доступа к плану
