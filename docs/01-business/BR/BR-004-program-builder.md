# BR-004: Управление тренировочными планами тренером

## Статус

| Параметр | Значение |
|----------|----------|
| **Статус** | ✅ APPROVE |
| **Дата утверждения** | 2026-04-29 |
| **Комментарий** | Поддерживающее требование для MVP с публичной ссылкой; канонический scope MVP см. BR-010 |
| **Приоритет MVP** | P0 только для тренерского плана с публичной ссылкой; solo-client перенесён после MVP |

## Business Value

Даёт тренеру основной рабочий сценарий MVP: быстро создать простой план для клиентской карточки, отправить публичную ссылку и увидеть выполнение.

## Приоритет реализации

- **MVP с публичной ссылкой:** создание простого индивидуального плана тренером, связь плана с минимальной клиентской карточкой, публичная ссылка на план и отметка выполнения клиентом без регистрации. Детали MVP закреплены в [BR-010](BR-010-public-plan-link-mvp.md).
- **Phase 2:** самостоятельное создание программ клиентом, шаблоны, библиотека упражнений, AI-генерация и автоматизации по событиям.


## User Stories

### US-R004-001: Назначение программы клиенту

* **As a** тренер
* **I want** создать план для клиентской карточки и отправить ссылку
* **So that** клиент видел план без регистрации и отмечал выполнение

**Acceptance Criteria:**

* **AC-R004-U001-001:**
    * **Given:** у тренера есть клиентская карточка
    * **When:** он создаёт простой план
    * **Then:** план связывается с выбранной клиентской карточкой
* **AC-R004-U001-002:**
    * **Given:** план создан
    * **When:** клиент открывает публичную ссылку
    * **Then:** он видит актуальный план без регистрации
* **AC-R004-U001-003:**
    * **Given:** клиент завершил тренировку
    * **When:** он отмечает выполнение
    * **Then:** я вижу статус выполнения в своей панели или карточке клиента
* **AC-R004-U001-004:**
    * **Given:** клиентская карточка и план существуют
    * **When:** я фиксирую выполненные упражнения или статус выполнения в назначенной программе
    * **Then:** изменения сохраняются как часть тренировочного процесса и не создают клиентский профиль в MVP

### US-R004-002: Редактирование и удаление программы

* **As a** тренер
* **I want** редактировать или удалять созданную программу
* **So that** корректировать план по мере изменения потребностей клиента

**Acceptance Criteria:**

* **AC-R004-U002-001:**
    * **Given:** я создал программу
    * **When:** я редактирую её содержание
    * **Then:** изменения сохраняются и клиент видит актуальную версию
* **AC-R004-U002-002:**
    * **Given:** программа не назначена ни одному клиенту
    * **When:** я удаляю программу
    * **Then:** она удаляется без влияния на историю клиентов

## System Constraints

| Constraint   | Value     | Notes |
|--------------|-----------|-------|
| Latency      | < 1200 ms | Создание/назначение программы |
| Throughput   | 25 req/sec | Создание и обновление простых планов |
| Availability | 99.5%     | Ядро ценности пилотного сценария |

## Метрики успеха

- ≥ 55% новых тренеров создают первый план в течение 7 дней;
- median time-to-first-plan-link ≤ 1 день.


## Out of Scope

- AI-генерация программ в MVP
- Шаблоны программ и библиотека упражнений
- Медицинские протоколы реабилитации
- Самостоятельное создание программы клиентом и solo-client PLG путь в MVP публичного доступа к плану
