## Business Value

Открывает сценарий совместной работы тренера, нутрициолога и реабилитолога внутри одного профиля клиента.

## Приоритет реализации

- **Связь с MVP:** не входит в обязательный первый коммерческий релиз; в MVP допустим только design reserve без production-функциональности multi-specialist.
- **Design-partner пилоты:** возможны после Gate 1 как контролируемые ручные проверки спроса, без обязательств включать сценарий в объём MVP.
- **Цель Phase 2:** полноценные роли специалистов, параллельный доступ, детальные scope и разграничение видимости по задачам.


## User Stories

### US-R003-001: Подключение нескольких специалистов

* **As a** клиент
* **I want** подключать нескольких специалистов
* **So that** они могли работать в одном контуре

**Acceptance Criteria:**

* **AC-R003-U001-001:**
    * **Given:** у меня уже есть активный тренер
    * **When:** я подключаю второго специалиста
    * **Then:** система не блокирует параллельную работу
* **AC-R003-U001-002:**
    * **Given:** у специалистов разные роли
    * **When:** они открывают мой профиль
    * **Then:** каждый видит только релевантный набор данных и задач

## Целевые допущения Phase 2

| Constraint   | Value     | Notes |
|--------------|-----------|-------|
| Latency      | < 1000 ms | Целевая гипотеза Phase 2 для проверки ролевого доступа |
| Throughput   | 20 req/sec | Стартовая гипотеза для design-partner пилотов Phase 2 |
| Availability | 99.5%     | Целевая доступность Phase 2; консистентность прав критична для доверия |

## Метрики успеха

- ≥ 12% платящих аккаунтов используют 2+ специалистов к концу 24-го месяца;
- ≥ 80% пилотных multi-specialist аккаунтов подтверждают ценность сценария в интервью.


## Out of Scope

- Маркетплейс специалистов
- Автоматическое распределение клиентов между специалистами
