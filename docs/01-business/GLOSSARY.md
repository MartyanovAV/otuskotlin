# Глоссарий FitBridge


---

## Термины

1. **Активный клиент MVP** — клиентская карточка тренера, по которой за последние 30 календарных дней произошло хотя бы одно значимое действие: создан план или обновлен статус. Для MVP продуктовые биллинговые лимиты не применяются.

2. **Связка тренер-клиент в MVP дневника тренера** — рабочая пара «тренер – клиентская карточка», созданная тренером для ведения планов. Обоюдное подтверждение через клиентский аккаунт не входит в MVP.

3. **Доступ (AccessGrant)** — будущая client-owned модель разрешения тренеру работать с данными клиента. В MVP дневника тренера `AccessGrant` не входит в scope; клиент не имеет доступа к системе.

4. **Тренировочный план (TrainingPlan)** — простой план, который тренер создаёт для клиентской карточки в MVP дневника тренера. Самостоятельное создание плана клиентом относится к Phase 2.

5. **Client-owned data** — будущая модель, при которой данные о тренировках принадлежат клиенту и сохраняются в его профиле независимо от подключённых тренеров. MVP дневника тренера не проверяет эту модель как обязательство первого релиза.

6. **Профиль клиента (ClientProfile)** — будущий client-owned профиль клиента с историей, доступами и настройками. В MVP дневника тренера клиентский профиль и регистрация клиента не входят в scope.

7. **Профиль тренера (TrainerProfile)** — профессиональный профиль тренера и минимальный рабочий кабинет; тренер является единственным зарегистрированным пользователем MVP дневника тренера.

8. **Клиентская карточка (ClientCard)** — минимальная карточка, которую тренер создаёт для клиента в MVP дневника тренера. Содержит только данные, необходимые для ведения плана; не является client-owned профилем.

9. **Приглашение (Invite)** — будущий механизм подключения клиента с подтверждением доступа. В MVP дневника тренера клиентский доступ отсутствует.

10. **Gate 1 (бизнес)** — продуктовая контрольная точка перехода от MVP к Phase 2. Решение принимается на основе метрик активации, retention и willingness-to-pay.

11. **PLG (Product-Led Growth)** — стратегия роста, при которой продукт сам является основным каналом привлечения и конверсии.

12. **Free-слой** — будущий бесплатный функционал для зарегистрированного клиента. В MVP дневника тренера отдельный клиентский free-слой, дневник, история и solo-client путь не входят в scope.

13. **Платящий аккаунт** — аккаунт тренера или студии с активной платной подпиской.

14. **Операционное администрирование пилота** — ограниченный внепродуктовый процесс сопровождения MVP. Может включать допуск или отзыв пилотных тренеров и обработку пилотных edge cases. Не является пользовательской ролью продукта и не даёт broad bypass к данным клиента.

15. **Support/ops оператор пилота** — участник операционного процесса MVP, который выполняет разрешённые действия для сопровождения пилота. Такой оператор не получает права читать чувствительные данные; действия фиксируются без чувствительных payload.

16. **ADMIN/support UI / support console** — продуктовый интерфейс администрирования и поддержки с отдельными операторскими сценариями. Для MVP не входит в scope; полноценный admin UI/support console и гранулярные operator roles относятся к Phase 2.
