# Глоссарий FitBridge


---

## Термины

1. **Активный клиент MVP** — клиентская карточка тренера, по которой за последние 30 календарных дней произошло хотя бы одно значимое действие по публичной ссылке: создан план, открыта публичная ссылка или оставлена отметка выполнения. Для MVP продуктовые биллинговые лимиты не применяются.

2. **Связка тренер-клиент в MVP публичного доступа к плану** — рабочая пара «тренер – клиентская карточка», созданная тренером для назначения плана и получения отметки выполнения. Обоюдное подтверждение через клиентский аккаунт не входит в MVP.

3. **Доступ (AccessGrant)** — будущая client-owned модель разрешения тренеру работать с данными клиента. В MVP публичного доступа к плану `AccessGrant` не входит в scope; клиент открывает план по публичной ссылке, а тренер может закрыть доступ по ссылке.

4. **Тренировочный план (TrainingPlan)** — простой план, который тренер создаёт для клиентской карточки в MVP публичного доступа к плану. Самостоятельное создание плана клиентом относится к Phase 2.

5. **Публичная ссылка на тренировочный план** — ссылка на тренировочный план, которую тренер отправляет клиенту вне продукта. Клиент открывает её без регистрации и может оставить отметку выполнения; тренер может закрыть доступ по ссылке.

6. **Отметка выполнения (CompletionMark)** — минимальная запись о выполнении плана или элемента плана клиентом по публичной ссылке. Не равна полноценной дневниковой записи клиента.

7. **Client-owned data** — будущая модель, при которой данные о тренировках принадлежат клиенту и сохраняются в его профиле независимо от подключённых тренеров. MVP публичного доступа к плану не проверяет эту модель как обязательство первого релиза.

8. **Профиль клиента (ClientProfile)** — будущий client-owned профиль клиента с историей, доступами и настройками. В MVP публичного доступа к плану клиентский профиль и регистрация клиента не входят в scope.

9. **Профиль тренера (TrainerProfile)** — профессиональный профиль тренера и минимальный рабочий кабинет; тренер является единственным зарегистрированным пользователем MVP публичного доступа к плану.

10. **Клиентская карточка (ClientCard)** — минимальная карточка, которую тренер создаёт для клиента в MVP публичного доступа к плану. Содержит только данные, необходимые для ведения плана и просмотра статуса выполнения; не является client-owned профилем.

11. **Приглашение (Invite)** — будущий механизм подключения клиента с подтверждением доступа. В MVP публичного доступа к плану заменён публичной ссылкой на план без регистрации клиента.

12. **Gate 1 (бизнес)** — продуктовая контрольная точка перехода от MVP к Phase 2. Решение принимается на основе метрик активации, retention и willingness-to-pay.

13. **PLG (Product-Led Growth)** — стратегия роста, при которой продукт сам является основным каналом привлечения и конверсии.

14. **Free-слой** — будущий бесплатный функционал для зарегистрированного клиента. В MVP публичного доступа к плану отдельный клиентский free-слой, дневник, история и solo-client путь не входят в scope.

15. **Платящий аккаунт** — аккаунт тренера или студии с активной платной подпиской.

16. **Операционное администрирование пилота** — ограниченный внепродуктовый процесс сопровождения MVP. Может включать допуск или отзыв пилотных тренеров и обработку пилотных edge cases. Не является пользовательской ролью продукта и не даёт broad bypass к данным клиента.

17. **Support/ops оператор пилота** — участник операционного процесса MVP, который выполняет разрешённые действия для сопровождения пилота. Такой оператор не получает права читать чувствительные данные; действия фиксируются без чувствительных payload.

18. **ADMIN/support UI / support console** — продуктовый интерфейс администрирования и поддержки с отдельными операторскими сценариями. Для MVP не входит в scope; полноценный admin UI/support console и гранулярные operator roles относятся к Phase 2.
