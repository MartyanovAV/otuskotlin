# MVP Scope Summary

| Параметр | Значение |

## Business Value

Фиксирует минимальный коммерческий объём FitBridge для Gate 1: что обязано войти в первый релиз, что остаётся design reserve и что явно перенесено после MVP.

## MVP Scope

| BR | Что входит в MVP |
|---|---|
| BR-001 | Профиль клиента, ручное внесение тренировок, замеров и заметок, бесплатный базовый доступ клиента |
| BR-002 | Выдача/отзыв доступа тренерам, экран текущих доступов, сохранение истории при смене тренера |
| BR-004 | Простая программа тренировок, шаблоны, назначение клиенту, отметка выполнения |
| BR-005 | Базовый отчёт по тренировкам, adherence и замерам за период |
| BR-006 | Регистрация тренера, мастер первого клиента, отправка приглашения, базовая рабочая панель |
| BR-007 | Отображение тарифа и лимитов, апгрейд, базовые автоплатежи, статусы оплаты и напоминания |

### Design reserve / pilot only
- **BR-003:** multi-specialist сценарий не входит в обязательный первый коммерческий релиз; допустим только ручной пилот и design reserve.
- **BR-008:** командный сценарий студии не входит в обязательный первый коммерческий релиз; допустимы только design-partner пилоты.

### Критический сквозной путь MVP
1. Тренер регистрируется.
2. Приглашает первого клиента.
3. Клиент принимает доступ и получает свой профиль/дневник.
4. Тренер назначает программу.
5. Клиент отмечает выполнение и данные попадают в базовый отчёт.
6. Тренер видит лимиты тарифа и может перейти на платный план.

## System Constraints

| Constraint | Value | Notes |
|-----------|-------|-------|
| Scope discipline | MVP only | BR-003 и BR-008 не являются обязательным scope первого релиза |
| Commercial readiness | Required | В релизе должны работать онбординг, программа, отчёт и базовый billing |
| Approval state | Draft | Документ предназначен для Gate 1, не является утверждённым scope |

## Out of Scope

- Полноценный multi-specialist production-сценарий
- Командный тариф и shared client operations для студий
- AI-генерация программ и продвинутая аналитика
- Полноценный club ERP, маркетплейс специалистов и медицинская диагностика
