# API Metrics and Limits

Продуктовые метрики, performance targets, rate limits, тарифные лимиты и требования надёжности.

#### 4. Бизнес-метрики успеха

**Продуктовые метрики**

| Метрика | Целевое значение MVP | Комментарий |
|---------|----------------------|-------------|
| Активация тренера | ≥ 60% зарегистрированных тренеров создают профиль и отправляют первое приглашение за 24 часа | BR-006 |
| Принятие приглашений | ≥ 50% приглашений принимаются клиентами за 7 дней | BR-002 |
| Ведение дневника | ≥ 3 записи дневника в неделю у активного клиента | BR-001 |
| Назначение плана | ≥ 55% новых тренеров назначают первый план в течение 7 дней | BR-004 |
| Отметка выполнения | ≥ 50% подключённых клиентов отмечают выполнение хотя бы одной назначенной тренировки | BR-005 |
| Готовность платить | ≥ 5 пилотных тренеров подтверждают willingness-to-pay после критического пути | BR-007 как ручная проверка вне продукта |

| Область | Лимит MVP | Примечание |

**Тарифные лимиты — Phase 2**

Тарифные лимиты не применяются в MVP API и не блокируют приглашения, назначение плана или просмотр истории в Gate 1.

| Тариф | Цена | Целевая аудитория | Ключевые лимиты |
|-------|------|-------------------|-----------------|
| Client Free | ₽0 | Клиенты | личный дневник, замеры, история, принятие приглашений |
| Coach Start | ₽1 490/мес | Соло-тренеры до 15 клиентов | 15 активных клиентов, базовые отчёты, 20 приглашений/сутки |
| Coach Pro | ₽2 990/мес | Тренеры 15-50 клиентов | 50 активных клиентов, расширенная аналитика, 100 приглашений/сутки |
| Studio Team | ₽5 990/мес | Команды и студии | командные роли, командные шаблоны, 300 приглашений/сутки |

**Надёжность и соответствие**

1. Доступность публичного API MVP: 99,5% в месяц.
2. Потеря подтверждённых записей дневника: 0 допустимых случаев.
3. Все операции выдачи и отзыва доступа должны иметь `AuditEvent` в 100% случаев.
4. Время вступления отзыва доступа в силу: не более 5 секунд для пользовательских API.
5. Восстановление после ошибки платежного webhook: повторная обработка без двойного списания в 100% идемпотентных сценариев.
   - *Scope*: Phase 2.
