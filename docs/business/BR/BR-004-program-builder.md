# BR-004: Назначение программ тренировок тренером

## Статус

| Параметр | Значение |
|----------|----------|
| **Статус** | ⬜ Черновик |
| **Дата утверждения** | 2026-04-29 |
| **Комментарий** | Базовая ежедневная ценность для тренера |

## Business Value

Даёт тренеру основной рабочий сценарий, без которого подписка не выглядит оправданной.

## Приоритет реализации

- **MVP:** создание простой программы, шаблоны, назначение клиенту, отметка выполнения.
- **Phase 2:** AI-генерация, библиотека сложных шаблонов, автоматизации по событиям.

## User Stories

### US-R004-001: Назначение программы клиенту

* **As a** тренер
* **I want** назначить клиенту программу
* **So that** клиент видел план и отмечал выполнение

**Acceptance Criteria:**

* **AC-R004-U001-001:**
    * **Given:** клиент подключён
    * **When:** я создаю или выбираю шаблон программы
    * **Then:** могу назначить её на конкретный период
* **AC-R004-U001-002:**
    * **Given:** программа назначена
    * **When:** клиент открывает приложение
    * **Then:** он видит актуальный план и ближайшие тренировки
* **AC-R004-U001-003:**
    * **Given:** клиент завершил тренировку
    * **When:** он отмечает выполнение
    * **Then:** я вижу статус выполнения в своей панели

## System Constraints

| Constraint   | Value     | Notes |
|--------------|-----------|-------|
| Latency      | < 1200 ms | Создание/назначение программы |
| Throughput   | 25 req/sec | С учётом шаблонов и обновлений |
| Availability | 99.5%     | Ядро ценности платного тарифа |

## Метрики успеха

- ≥ 55% новых тренеров создают первую программу в течение 7 дней;
- median time-to-first-program ≤ 1 день.

## Out of Scope

- AI-генерация программ в MVP
- Медицинские протоколы реабилитации
