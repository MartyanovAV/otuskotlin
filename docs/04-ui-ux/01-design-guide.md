# FitBridge UI Design Guide

Этот документ описывает визуальную систему и компоненты проекта FitBridge, основываясь на разработанных прототипах. Он служит единым источником правды для разработчиков и дизайнеров при масштабировании приложения.

## 1. Философия и Эстетика

> [!NOTE]
> **Energy + Trust (Энергия и Доверие)**
> Дизайн совмещает глубокие и надежные синие/индиго оттенки (символизирующие платформу-мост "Bridge") с ярким лаймовым акцентом (символизирующим пульс, энергию и фитнес). 

- **Современность**: Использование скругленных углов (Squircle), мягких теней и эффектов размытия (Glassmorphism).
- **Динамика**: Плавная типографика (`clamp`), интерактивные ховеры и состояния фокуса.
- **Контрастность**: Четкое разделение контента через систему поверхностей (Surface 1, 2, 3) как в светлой, так и в темной теме.

## 2. Цветовая Палитра

Система построена на семантических переменных (`--bg`, `--surface`, `--primary`), что позволяет легко переключать темы (`[data-theme='dark']`).

| Назначение | Токен | Значение (HEX) |
| :--- | :--- | :--- |
| **Фон (Background)** | `--bg` | `#f5f6f8` |
| **Поверхности** | `--surface`, `--surface-2`, `--surface-3` | `#ffffff`, `#f0f2f5`, `#e6e9ee` |
| **Границы** | `--border`, `--divider` | `#e3e6eb`, `#ecedf0` |
| **Текст** | `--text`, `--text-muted`, `--text-faint` | `#15181d`, `#62676f`, `#a1a5ac` |
| **Primary (Акцентный синий)** | `--primary` | `#3b3df3` (Hover: `#2f31d6`) |
| **Accent (Лаймовый пульс)**| `--accent` | `#c8ff3a` |

### Темная Тема (Dark)
| Назначение | Токен | Значение (HEX) |
| :--- | :--- | :--- |
| **Фон (Background)** | `--bg` | `#0d0e11` |
| **Поверхности** | `--surface`, `--surface-2`, `--surface-3` | `#16181d`, `#1d2026`, `#262a31` |

### Статусные Цвета
- **Success (Успех)**: `#14a76c` (Light) / `#34d399` (Dark)
- **Warning (Внимание)**: `#f5a623` (Light) / `#fbbf24` (Dark)
- **Danger (Ошибка)**: `#e2453d` (Light) / `#f87171` (Dark)
- **Info (Информация)**: `#0a8fc7` (Light) / `#38bdf8` (Dark)

*(Каждый статус также имеет `-soft` версию для фонов бейджей и уведомлений).*

## 3. Типографика

Для обеспечения идеальной читаемости и современного вида используются разные шрифты для заголовков и набора.

- **Display (Заголовки)**: `Manrope`, `Inter`, sans-serif
- **Body (Основной текст)**: `Inter`, system-ui, sans-serif
- **Mono (Код/цифры)**: `JetBrains Mono`, monospace

> [!TIP]
> В проекте используется **Fluid Typography** (плавная типографика на основе `clamp()`), которая автоматически адаптируется под размер экрана. Не используйте жесткие значения в пикселях для шрифтов.

**Шкала размеров:**
- `--text-xs`: 12-13px (вспомогательный текст)
- `--text-sm`: 13-15px (метаданные, мелкий UI)
- `--text-base`: 15-16px (основной текст)
- `--text-md`: 16-18px (подзаголовки)
- `--text-lg`: 18-22px (заголовки карточек)
- `--text-xl`: 22-28px (заголовки разделов)
- `--text-2xl`: 28-36px (главные заголовки)

## 4. Пространство и Геометрия

### Сетка отступов (4px Scale)
Используйте строго заданные токены для `margin` и `padding`, чтобы обеспечить ритм.
`--s-1` (4px), `--s-2` (8px), `--s-3` (12px), `--s-4` (16px), `--s-5` (20px), `--s-6` (24px), `--s-8` (32px).

### Скругления углов (Radii)
- `--r-sm` (8px): Мелкие элементы (инпуты, теги).
- `--r-md` (12px): Кнопки, небольшие карточки.
- `--r-lg` (16px): Основные панели, графики, виджеты.
- `--r-xl` (22px): Крупные модальные окна, Hero-баннеры.
- `--r-full` (9999px): Аватары, круглые кнопки, бейджи.

### Тени (Elevation)
- `--shadow-sm`: Повседневный UI (кнопки, плашки).
- `--shadow-md`: Карточки (hover состояния), выпадающие списки.
- `--shadow-lg`: Модальные окна, тултипы.

## 5. Компоненты UI (Спецификация)

### Кнопки (`.btn-d`)
- **Форма**: `border-radius: 10px`, `padding: 9px 16px`.
- **Типографика**: Font size 13px, font-weight 600, дисплейный или базовый шрифт.
- **Варианты**:
  - `primary`: Синий фон, белый текст. Hover: Затемнение основного.
  - `ghost`: Прозрачный фон, Hover: `--surface-2`.

### Карточки (`.card-d`, `.kpi-card`)
- **Фон**: `--surface`
- **Граница**: `1px solid var(--border)`
- **Углы**: `--r-lg` (16px)
- **Внутренние отступы**: `18px 20px` для тела карточки.
- Заголовок отделяется `1px solid var(--divider)` (если предусмотрена шапка карточки).

### Текстовые поля / Поиск (`.search input`)
- **Фон**: В неактивном состоянии `--surface-2` (без явной границы).
- **Фокус**: Переход фона в `--surface` и появление рамки цвета `--primary`. Пластичная анимация перехода `120ms`.
- **Углы**: 10px.

### Аватары (`.avt`)
- Размеры: `32x32` (стандарт), `64x64` (lg, профиль).
- Если нет фото, используется радиальный или линейный градиент (135deg). Например, от оранжевого к розовому или от фиолетового к синему.

### Бейджи / Теги (`.pill-d`)
- Исключительно закругленные (pill-shape): `border-radius: 999px`.
- **Цвет**: Используется `--[status]-soft` для фона и `--[status]` для текста. Это улучшает читаемость и не перегружает интерфейс яркими пятнами.

## 6. Layout и Скелет Приложения

> [!IMPORTANT]
> Приложение строится по модели **App Shell** с фиксированной левой колонкой (Rail) и прокручиваемой областью контента (View).

- **Навигация (Sidebar/Rail)**: Фон `--surface`, правая граница `1px var(--border)`. Активный пункт меню выделяется фоном `--primary-soft`.
- **Top Bar (Шапка)**: Полупрозрачность и блюр (`backdrop-filter: blur(12px)` + `rgba` фон) для создания эффекта матового стекла (Glassmorphism).
- **Сетка контента**: Максимальная ширина `1440px`. Использование CSS Grid (`.cols-2`, `.cols-3`) для метрик (KPI) и панелей дашборда.

## 7. Анимация и Интерактивность
Все переходы состояний (hover, focus, active) должны быть быстрыми и "пружинистыми" (snappy).
- Стандартное время перехода (transition): `120ms` (для кнопок и ссылок) или `180ms` (для навигации).
- Смена вкладок (`.view.active`) сопровождается мягким фейдом и сдвигом `fade-in 0.25s ease`.
